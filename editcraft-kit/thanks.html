ダウンロード

Google Drive を開く

お使いの OS に合う ZIP をダウンロードしてください。アップデートも同じ場所に置かれます。

  • Windows → EditcraftKit_v◯_Windows.zip
  • Mac → EditcraftKit_v◯_Mac.zip

使い始めるまで

  1. ZIP を展開します（Windows は右クリック →「すべて展開」）。展開先は「ダウンロード」など PC 本体のフォルダにしてください。
  2. Windows は 1_Install.cmd、Mac は Install.command（右クリック →「開く」）を実行します。
  3. 画面の案内に沿って進め、最後に Creative Cloud の「インストール」を押します。
  4. Premiere Pro を再起動し、［ウィンドウ］→［UXP プラグイン］→［Editcraft Kit］を開きます。
  5. 上のライセンスキーを貼り付けて「登録する」を押せば完了です。

詳しくは ZIP に入っている Guide.html（説明書）、または オンライン版の説明書をご覧ください。
